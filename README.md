# 채권/IRS 트레이딩 대시보드

인포맥스에서 뽑은 채권시장 데이터를 스프레드 거래/환거래 관점에서 볼 수 있는 대시보드.

## 데이터 업데이트 흐름

1. 인포맥스 연동 엑셀(`RawData.xlsx`, IMDH 함수로 자동 갱신)을 `data/RawData.xlsx` 에 덮어쓰기
2. "데이터 업데이트했어" 라고 알려주면 반영 (git commit/push → Streamlit Cloud 자동 재배포)

## 원본 데이터 구조 (`data/RawData.xlsx`)

`data_loader.py` 가 파일을 열어 row2(IMDH 수식/블록 제목)와 row3(만기 등 서브헤더)를 스캔해서
자동으로 블록을 인식하므로, 컬럼 위치가 하드코딩되어 있지 않다 — 인포맥스에서 커브를 추가/삭제해도
같은 레이아웃 규칙만 지키면 그대로 동작한다.

- **Info(국내금리)** 시트: 국고채/통안채/은행채/카드채/기타금융채/회사채(등급별) 커브(1,2,3,4,5,10,20,30년),
  원화 IRS 종합코드(6개월~30년, 20개 포인트)
- **Info(단기금리)** 시트: 기준금리, CD(91일)
- **Info(해외금리)** 시트: 미국/독일/영국/프랑스/이탈리아/일본/호주/캐나다/인도/인도네시아/브라질/멕시코/남아공 국채 금리 (아직 대시보드에는 미반영 — 항목 정해지면 추가 예정)
- A열 = 날짜, row4부터 아래로 데이터. 값이 `0`이면 "해당 만기 데이터 없음"으로 간주하고 건너뜀
- row1 F열("Data 개수")로 히스토리 길이를 조절할 수 있음 (현재 99999 = 사실상 전체 히스토리, 1994년부터).
  날짜가 시작일부터 쭉 채워지는 것과 별개로 실제 값이 있는 행만 걸러서 쓰므로, 이 값을 바꿔도 코드 수정은 필요 없음

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 현재 범위

- 🏛️ 국고채/통안채 금리커브 (스냅샷 + 날짜 비교 + 만기별 히스토리)
- 🏦 신용스프레드 (은행채/카드채/기타금융채/회사채 등급별 vs 국고채·통안채, bp + 등급 사다리)
- 🔁 IRS 커브 / 본드스왑 스프레드 (IRS-국고채, bp)
- 📉 단기금리 (기준금리, CD 91일)

추후 CRS/FX스왑포인트/재정거래 등은 관련 인포맥스 데이터가 추가되면 확장 예정.
