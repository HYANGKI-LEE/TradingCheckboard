# 채권/IRS 트레이딩 대시보드

인포맥스에서 뽑은 채권시장 데이터를 스프레드 거래/환거래 관점에서 볼 수 있는 대시보드.

## 데이터 업데이트 흐름

1. 인포맥스 엑셀(함수로 자동 갱신되는 시트)에서 값을 `data/curve_data.xlsx` 형식으로 정리
2. "데이터 업데이트했어" 라고 알려주면 반영 (git commit/push → Streamlit Cloud 자동 재배포)

## 기대하는 엑셀 구조 (`data/curve_data.xlsx`, 시트명 `커브데이터`)

| 날짜 | 만기 | 국고채금리 | IRS금리 |
|---|---|---|---|
| 2026-09-10 | 1Y | 2.85 | 2.95 |
| 2026-09-10 | 3Y | 2.80 | 2.92 |

- 만기: `3M, 6M, 9M, 1Y, 1.5Y, 2Y, 3Y, 4Y, 5Y, 7Y, 10Y, 20Y, 30Y, 50Y` 중 사용하는 것만
- 국고채금리 / IRS금리: %, 둘 중 하나가 비어 있어도 됨

실제 파일이 `data/curve_data.xlsx` 로 들어오기 전까지는 동일한 형식의 샘플(더미) 데이터로 대시보드가 동작한다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 현재 범위 (1차)

- 🏛️ 국고채 금리커브 (스냅샷 + 날짜 비교 + 만기별 히스토리)
- 🔁 IRS 커브 / 본드스왑 스프레드 (IRS-국고채, bp)

추후 CRS/FX스왑포인트/재정거래 등은 인포맥스 파일 구조를 보고 확장 예정.
